# Apex Aim Trainer

An aim trainer built around how Apex Legends plays: projectile weapons, recoil patterns,
Titanfall-style target movement, high health pools, and legend-sized hitboxes.

## Layout

- `assets/models/`: game-ready target dummies (`.glb`) with animations and bone-attached hitboxes
- `art/`: the scripts and config that build those assets; see [art/README.md](art/README.md)
